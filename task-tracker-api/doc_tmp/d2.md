# Module 4 — D2: Docker Artifacts Verification

Files inspected: `Dockerfile`, `.dockerignore`

## 1. Commands to run

**Build the image**
```bash
docker build -t task-tracker:dev .
```

**Start the container on port 8000** (removes any existing `tt-dev` first to avoid a name conflict)
```bash
docker rm -f tt-dev 2>/dev/null; docker run -d --name tt-dev -p 8000:8000 task-tracker:dev
```

**GET /health through the container's port mapping**
```bash
curl -s -o /dev/null -w "HTTP %{http_code}\n" http://localhost:8000/health
curl -s http://localhost:8000/health
```

**Confirm the container runs as `app`, not root**
```bash
docker exec tt-dev whoami
docker inspect --format='{{.Config.User}}' tt-dev
```

**Confirm `.dockerignore` excludes `.env`, `.git`, virtual envs, and caches**
```bash
grep -E '^\.env|^\.env\.\*|^\.git$|^venv/|^\.venv/|__pycache__|\.pytest_cache|\.coverage|htmlcov' .dockerignore
```
Cross-check that none of those actually made it into the built image:
```bash
docker run --rm task-tracker:dev sh -c "find /app -iname '.env*' -o -iname '.git' -o -iname 'venv' -o -iname '.venv' -o -iname '__pycache__'"
```

**Confirm the Dockerfile doesn't copy secrets or use `python:latest`**
```bash
grep -n '^FROM' Dockerfile
grep -inE '\.env|secret|COPY \. \.' Dockerfile
```
