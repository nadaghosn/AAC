# Module 4 Dockerfile — Design + Draft

## Design Summary

- **Builder stage** (`python:3.11-slim`, pinned tag): creates a virtualenv at `/opt/venv`, then installs `requirements.txt` into it via `pip install` — keeps pip's build cache and any compiler artifacts entirely out of the runtime image.
- **Runtime stage** (`python:3.11-slim`, pinned tag): starts fresh. Only two things get copied in — the populated `/opt/venv` from the builder, and the `app/` source directory. Nothing else (no `requirements.txt`, no tests/docs/frontend/`.git`, no build tools).
- **Non-root user**: `app`, fixed `--uid 1000`, no home directory, `nologin` shell (least privilege — it never needs a home dir or interactive shell). `/app` ownership is set to `app:app` before switching users.
- **`USER app`** appears before `EXPOSE`, `HEALTHCHECK`, and `CMD` — root never runs the app process.
- **`HEALTHCHECK`**: pure Python stdlib (`urllib.request.urlopen` against `http://127.0.0.1:8000/health`), exec-form `CMD` array — no `curl` installed, so the image stays smaller and has one less package to patch. `urlopen` raises on non-2xx, so the interpreter's own non-zero exit on an unhandled exception is what marks the check unhealthy — no extra exit-code plumbing needed. `--interval=30s --timeout=5s` exactly as specified.
- **No secrets**: nothing under `.env*` is referenced or copied; secrets would only ever enter via runtime env vars, which is out of scope for this Dockerfile itself.
- **Final `CMD`**: exec-form `["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]` — no `--reload`.
- **Nothing else**: no docker-compose, Kubernetes manifests, buildx config, or other deployment files.

## Dockerfile (draft — not yet applied to the repo)

```dockerfile
# ---- builder stage ----
FROM python:3.11-slim AS builder

WORKDIR /app

RUN python -m venv /opt/venv
ENV PATH="/opt/venv/bin:$PATH"

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# ---- runtime stage ----
FROM python:3.11-slim AS runtime

RUN useradd --uid 1000 --no-create-home --shell /usr/sbin/nologin app

WORKDIR /app

COPY --from=builder /opt/venv /opt/venv
COPY app ./app

RUN chown -R app:app /app

ENV PATH="/opt/venv/bin:$PATH"

USER app

EXPOSE 8000

HEALTHCHECK --interval=30s --timeout=5s CMD ["python", "-c", "import urllib.request; urllib.request.urlopen('http://127.0.0.1:8000/health', timeout=5)"]

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```
